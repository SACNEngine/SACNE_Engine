# SACN_Engine
Sacn is a custom, free C# game engine developed by the Acn development team based on Stride. Dissatisfied with Stride's slow updates and limited features, they created Sacn to improve and enhance it significantly. It includes numerous new improvements and optimizations, keeps pace with official Stride updates, and even stays ahead of the official version.
